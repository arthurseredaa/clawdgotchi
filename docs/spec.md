# Clawdgotchi — специфікація

Дата: 2026-10-02 · Статус: реалізовано, оновлено після живої перевірки

## 1. Що це

Мод для Claude Code. Над промптом живе піксельний Clawd (маскот з лого Claude Code). Він товстішає разом із заповненням вікна контексту, а перед лімітом ледь не лускає. Після `/compact` лускає і вилуплюється знову маленьким.

Мета: заповненість контексту видно краєм ока, без читання цифр, і вчасно зрозуміло, що пора робити `/compact`.

Open source, ставиться з GitHub однією командою.

### Не входить у базову версію

- Механіка турботи (настрій, рівні, еволюція, статистика між сесіями).
- Репліки й фрази персонажа.
- Desktop-застосунок понад текстовий запасний рядок.
- Налаштування через `userConfig`.

## 2. Що бачить користувач

Смуга над промптом (render site `AbovePrompt`) — лише анімований Clawd, 4 рядки, без тексту. Точні цифри контексту більшість людей і так тримає в statusline (рішення Arthur, 2026-10-02).

- Спрайт: 8 пікселів заввишки, у сітці `Raster` 4 рядки, у правому куті смуги (рішення Arthur, 2026-10-02). Ширина сітки залежить від стадії: тіло + руки + 3 колонки для ефектів (16, 18, 18, 20, 22 колонки; під час «Лускає» — 22). Сітка віддзеркалена: Clawd притиснутий до правого краю, «z», крихти й піт з'являються ліворуч від нього, ноги стоять на тій самій відстані від правого краю на кожній стадії.
- Між Clawd і правим краєм смуги лишається 4 колонки під кнопку згортання `[-]`, яку Claude Code малює у верхньому правому куті.
- Пікселі малюються кольором символу: суцільна клітинка — `█`, половинка — `▀`/`▄`, порожня — пробіл. Колір фону — лише в клітинці з двома різними кольорами, і тоді для темнішого. Причина: iTerm2 з прозорістю вікна змішує кожен колір фону з робочим столом, і пікселі фоном виглядали темнішими смугами.
- Кнопку згортання `[-]` малює сам Claude Code; мод її не прибирає (API не дозволяє) і власного згортання не додає (рішення Arthur, 2026-10-02).
- Desktop-застосунок не малює `Raster`, тому там мод нічого не показує.

Перевірено в живій сесії (v2.1.284, 2026-10-02): `maxRows = 13`, Raster займає рівно 4 рядки, `$.ui.blit` з `requestId: 'above-prompt'` анімує без помилок, смуга лишається на місці, поки Клод працює.

## 3. Стадії

Межі за відсотком використаного контексту:

| Відсоток | Стадія | Тіло (ш×в) | Ноги | Кути | Колір | Очі | Холості рухи |
|---|---|---|---|---|---|---|---|
| 0–24 | Легкий | 10×5 | 2 | прямі | `#D97757` | крапки 1×2, кліпають | дихає: тіло присідає на 1 px |
| 25–49 | Ситий | 12×5 | 2 | прямі | `#DB7253` | `^ ^` | дихає |
| 50–74 | Наїдений | 12×6 | 2 | зрізані | `#DE6A4C` | примружені, крапля поту `#6FB7FF` | дихає повільніше |
| 75–89 | Роздутий | 14×6 | 1 | зрізані | `#E25C40` | витріщені 2×2 з відблиском, рум'янець `#F59A9A` | тіло хитається ±1 px |
| 90–100 | Ось-ось лусне | 16×7 | 1 | сильно зрізані | `#E8452E` | `×` 3×3, тріщини `#6E2416` | тремтить, мигає `#FF8A5C` |

Базова форма (стадія «Легкий») повторює лого: тіло, по одній руці 1×2 з боків на рівні нижньої третини, чотири ноги на колонках `1, 3, w−4, w−2`.

### Головне правило фізики

Ноги завжди стоять на нижньому ряду і на тих самих колонках. Рухається тільки тіло: присідає (ноги коротшають, але не відриваються), зсувається вбік, роздувається. Колонки ніг рахуються від базової ширини стадії, а не від поточної ширини тіла.

## 4. Події й анімації

Таймер ~8 кадрів/с (125 мс). Кожен кадр перемальовує тільки спрайт через `$.ui.blit({ requestId: 'above-prompt', key: 'clawd', columns: 20, rows: 4, cells })`. Текст оновлюється через `$.state`, який сам перемальовує смугу.

| Режим | Коли вмикається | Коли вимикається | Що відбувається |
|---|---|---|---|
| Працює | `turn.start` | `turn.complete` | тіло погойдується, руки по черзі «друкують» |
| Їсть | `turn.complete` з приростом > 0 | через 1.6 с | три «крихти» летять справа в тіло, тіло роздувається на 2 px і присідає в такт |
| Спить | 5 хв без `turn.start` | `turn.start` або `prompt.submit` | очі заплющені, тіло нерухоме; поруч по черзі з'являються літери `z z Z` (символи в клітинках Raster, не пікселі) |
| Лускає | `session.compact` (`manual`, `auto`, `plugin`; не для субагентів) | коли стиснення завершилось, + 0.6 с | див. нижче |
| Спокій | інакше | — | холості рухи стадії |

Пріоритет, якщо збіглося кілька: Лускає > Їсть > Працює > Спить > Спокій.

Послідовність «Лускає» (вибух 1.3 с, далі яйце хитається, доки йде стиснення, максимум 90 с, потім 0.6 с вилуплення; якщо стиснення швидше, вибух усе одно догравається):
1. 0–0.5 с — тіло стадії 4 трясеться, з 0.38 с спалахує білим.
2. 0.5–1.3 с — спалах у центрі, ~22 пікселі розлітаються з легкою «гравітацією».
3. яйце 5×5 на землі, з 1.6 с похитується, доки `next(e)` у `session.compact` не повернеться; тоді тріщина.
4. 2.3–2.6 с — з'являється Clawd стадії «Легкий», присідає і випрямляється. Поруч на землі шматочки шкаралупи.

Після кінця анімації стадія береться з нового значення контексту.

## 4a. Додатки (2026-10-02)

- **Дітки-субагенти.** `agent.spawn` з `agentId` додає малюка (5×3 пікселі, слот 7 колонок, максимум 3) біля Clawd з боку ефектів; `turn.complete` з тим самим `agentId`, `classic.SubagentStop` або звірка з `$.agent.list()` раз на 2 с (статус не `running`/`pending`) прибирає.
- **Нічний режим.** Година з `new Date(now).getHours()` (середовище модів бачить місцевий пояс): 23:00–01:59 спокій стає «сонним» (очі напівзаплющені, повільне дихання), 02:00–05:59 «працює» стає «спить».
- **Паспорт `/clawd`.** `$.store` (спільний для всіх сесій): `born`, `sessions` (лише `classic.SessionStart` з `source: startup`), `eaten` (додатний приріст за хід), `pops` (успішні стиснення), `babies`. Команда відкриває панель `clawd`: Clawd і рядки англійською (рішення Arthur, 2026-10-02): `Age`, `Sessions`, `Ate`, `Popped`, `Babies`.
- **«Чекає на тебе»** прибрано (рішення Arthur, 2026-10-02): поки відкритий діалог дозволу чи питання, Claude Code ховає смугу над промптом, тож стан у власній сесії не видно.
- Смуга, нижча за 4 рядки (`maxRows < 4`), — мод нічого не малює замість обрізаного спрайта з «↓ more».

## 5. Дані

- Джерело: `$.session.usage()` → `context.tokens`, `context.window`, `context.percent`.
- Коли читати: на `session.start`, після `turn.complete`, на `session.measure`.
- Приріст за хід рахується лише для режиму «Їсть» (різниця токенів між ходами), у смузі не показується.
- Зберігання в `$.state` (переживає hot reload): `reading` `{ tokens, window, percent }`. Режим анімації і номер кадру — змінні модуля.
- `tokens` і `percent` бувають відсутні (свіжа сесія, щойно після стиснення): тоді лишається останнє читання, а якщо його немає — 0%.
- `/clear`, `/resume`, `/branch` скидають `$.state`. На `classic.SessionStart` з `source` `clear | resume | fork` мод заново читає `usage()`.

## 6. Помилки й запасні шляхи

- `usage()` впав — лишається останнє читання. Якщо читань ще не було, мод повертає `next(e)` і нічого не малює.
- `$.ui.blit` кинув помилку — перемикаємось на `$.ui.invalidate('ui.render')` з тією ж частотою (смуга дозволяє до 30 перемальовок/с).
- `e.surface !== 'terminal'` (Desktop) — мод повертає `next(e)` і нічого не малює.
- `props.hasSurvey` — мод поступається смугою опитуванню.
- Інші моди в смузі: результат `await next(e)` додається під нашим блоком, щоб не затирати їхній вміст.
- Після старту сесії, гарячого перезавантаження чи оновлення плагіна мод викликає `$.ui.invalidate('ui.render')`, інакше смуга лишається з малюнком старої версії модуля.
- Будь-яка помилка в хуку не повинна ламати смугу: хуки мають `.catch`, який повертає `next(e)`.

## 8. Тести

Через `claude plugin test` з `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`.

- `sprite.test.ts`:
  - межі стадій 0/24/25/49/50/74/75/89/90/100;
  - кожен кадр кожного режиму вміщається в 20×8;
  - **ноги на місці:** для кожної стадії й кожного режиму в кадрах 0–47 нижній ряд має ті самі пікселі ніг, що й у кадрі 0;
  - послідовність «Лускає» дає непорожні кадри на кожному етапі і закінчується стадією «Легкий».
- `cells.test.ts`: порожні половинки прозорі, суцільні клітинки — `█`, у двоколірній клітинці світліший колір — символ.
- `scene.test.ts`: пріоритети режимів, яйце чекає кінця стиснення, швидке стиснення догравує вибух.
- `clawdgotchi.test.ts` (з test kit: `mock.clock`, стаби `session.usage`):
  - після двох `turn.complete` смуга (`$.ui.mount` для `AbovePrompt`) містить лише `Raster` з ключем `clawd` шириною 18 у кольорі стадії «Наїдений», без жодного тексту;
  - `session.compact` вмикає «Лускає», через 2.6 с годинника режим повертається;
  - помилка `usage()` до першого читання — смуга повертає `next(e)`;
  - `surface: 'desktop'` — мод нічого не малює.
- Жива перевірка: я сам запускаю мод у сусідній панелі herdr, роблю кілька ходів і `/compact`, звіряю екран через `herdr pane read --format ansi`.

## 9. README і встановлення

README містить:
- гіфку або скріншоти стадій;
- вимоги: Claude Code з модами (документація каже v2.1.287+, перевірено й на 2.1.284) і `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` в оточенні або в `env` у `~/.claude/settings.json`, поки моди в ранньому доступі;
- встановлення:
  - у сесії: `/plugin install clawdgotchi --marketplace arthurseredaa/clawdgotchi`
  - або в терміналі: `claude plugin marketplace add arthurseredaa/clawdgotchi`, потім `claude plugin install clawdgotchi@clawdgotchi`
- локальну розробку: `claude --plugin-dir .`, `claude plugin validate .`, `claude plugin test`;
- примітку: неофіційний фанатський проєкт, не пов'язаний з Anthropic; Clawd — персонаж Anthropic; логотипи Anthropic не використовуються.

Перед релізом: `claude plugin validate --strict .` проходить, установка з локального маркетплейсу (`claude plugin marketplace add ./`) працює в новій сесії.
